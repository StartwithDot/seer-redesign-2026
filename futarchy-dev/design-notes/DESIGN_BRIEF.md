# Futarchy v2: "Parallel Lanes" design brief (EF foundation, new visual world)
Product truth (unchanged, from the live app): each milestone is a conditional market. If the proposal PASSES, the milestone metric is priced one way; if it FAILS, another. The GAP between the two forecasts is the verdict; the DAO keeps the decision. Every existing feature, route, control, tooltip, modal, tour step, command palette entry and data-testid stays.

## Foundation (EF, from the kit): keep
Near-black surfaces (dark page #101013, card #1A1A1E, nested #1F1F24), text #EDEDF2 / #A8A8B3 / #67676F, light mode #F7F7F9 / #FFFFFF / #17171C, primary action EF violet #7B3AFF (secondary #241E33 with text #9C6FF2; light #EFE9FC with #6C2BD9), Inter Tight with tabular numerals, no borders (tonal steps), radii 16 / 12 / 8.

## What changes (it must NOT look like the current version)
- COLOR ROLES (STRICT EF PALETTE ONLY, no new hues): the EF kit has only neutrals and violet. PASS world = EF violet: line/fill #8A55FF, soft surface #241E33, text #9C6FF2 (light mode: #6C2BD9 / #EFE9FC). FAIL world = EF tint-white and graphite, never a new hue: line #D8CBFF, surface #1F1F24, text #C9B6FF (light mode: #5C5C66 / #F0F0F3). GAP = EF violet #7B3AFF at 24% flat fill (light #6C2BD9). Primary actions EF violet #7B3AFF with white text; secondary #241E33 with #9C6FF2 (light #EFE9FC with #6C2BD9). Only status semantics may add green #3DDC97 (up) and red #FF5C72 (down), used sparingly for deltas. NO blue, NO orange/ember, NO teal, NO periwinkle anywhere. Differentiate PASS vs FAIL by tone, line style (PASS solid 2px, FAIL 2px with a 6/4 dash) and direct labels, not by hue. Surfaces strictly #101013 / #1A1A1E / #1F1F24 dark and #F7F7F9 / #FFFFFF / #F0F0F3 light; text #EDEDF2 / #A8A8B3 / #67676F dark and #17171C / #5C5C66 / #8E8E99 light.
- LAYOUT: from "cards and signal board" to LANES. Every milestone is a full-width LANE: two thin horizontal tracks (PASS above, FAIL below) with the live forecast values at the right end, a single GAP bar between them that grows toward the leading side, and a verdict needle (Include / Neutral / Exclude). Landing = a left rail of organisations (sticky) + the lane board; the hero becomes a compact "decision strip" (what is being decided, count of live lanes, next resolution) not a big card. Detail = chart left (wide), a sticky right column (verdict gauge, trade panel, metrics), activity table below. Same components, rearranged and resized.
- CHART: flat fills only. Two step lines with direct end labels (no legend), a flat tinted GAP ribbon between them coloured by whichever side leads, a thin dashed decision threshold, snapping crosshair with a compact tooltip card, soft pulse dot on the latest trade. Axes: 8px grid, 11px labels, tabular numerals, gridlines at 6% opacity.
- BUTTONS (new family): tactile pill buttons with 1px inner top highlight, 120ms press translateY(1px), focus ring 2px offset; primary violet; secondary tonal; ghost; icon buttons 40px round; segmented control with a SLIDING thumb (transform based, 220ms spring-like cubic-bezier(.2,.8,.2,1)); chips for filters with check glyph when active. Keep the Uiverse bubbles effect on the primary CTA only if it exists now.
- ICONS: one custom icon set, 24px grid, 1.75px stroke, round caps and joins, written as inline SVG React components in src/components/icons.tsx (no emoji, no icon libraries). Needed: arrow-right, arrow-up-right, chevron-down, check, x, search, sun, moon, wallet, plus, minus, info, help, play, pause, clock, flag, users, layers, link, external, copy, filter, bolt, fork (PASS/FAIL split), gauge.
- MOTION (purposeful): lanes enter with a 40ms stagger (translateY 8px + fade, 320ms), the GAP bar and needle animate with transform and opacity only, numbers roll (existing RollingNumber), hover on a lane dims the other lanes to 60%, view-transition for theme switch kept, route change fade 180ms. Everything off under prefers-reduced-motion.
- TYPE SCALE (1.25): 12 / 14 / 16 / 20 / 25 / 31 / 39 / 49; body 14; numerals tabular; headings Inter Tight 600, tracking -0.01em; labels 11 to 12px uppercase tracking 0.06em only for tiny captions.
- SPACING: 8px base grid (4px only for icon gaps), page gutter 24px (16px under 640px), max content width 1392px at 1440, section gap 32px, card padding 24px.

## Non-negotiables
No glow gradients, no blurred orbs, no glassmorphism, no purple-to-pink, no emoji icons, no em dashes in copy, no placeholder text, contrast at least 4.5:1, focus rings always visible, touch targets at least 40px, no horizontal scroll at 390px, light and dark both polished.
