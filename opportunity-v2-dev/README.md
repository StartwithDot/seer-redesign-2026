# Opportunity Markets v2 (dev copy)
Copy of apps/opportunity-v2 from the Seer six-interface project (snapshot 2026-10-25, 32/34 e2e checks passing).
Run: `npm install && npm run dev` (Vite). Build: `npm run build`. E2E: `npm run e2e` (needs Google Chrome).
Design specs, parity checklist and the model-written audit are in ./docs.
Fonts load from the jsDelivr CDN (Geist, Geist Mono). The shared @seer/ef package is not required.
