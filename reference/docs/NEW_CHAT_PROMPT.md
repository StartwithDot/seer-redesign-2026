# Start of any new chat: read docs/HANDOFF_NEXT_PRODUCT.md (it has ready-to-paste start messages per product) and docs/RESEARCH_PROTOCOL.md (hard gate: full audit before design).
Short version of the rules: (1) crawl and audit the live product completely first (pipeline/audit_capture.mjs + audit_digest.py + DeepSeek), (2) user-centered analysis, (3) innovation research with a performance spike, (4) three concepts and a decision, (5) design.md with a trace table, (6) Codex passes, e2e outside Codex, real viewport screenshots, Opus review. Use free tools (crawler, DeepSeek, gh) for everything they can do. Do not commit, push or deploy without the user's OK.
