This function is called at the end of a safeTransferFrom after the balance has been updated. To accept the transfer, this must return bytes4(keccak256(&quot;onERC1155Received(address,address,uint256,uint256,bytes)&quot;)) (i.e. 0xf23a6e61, or its own function selector).
