> ## Documentation Index > Fetch the complete documentation index at: https://docs.seer.pm/llms.txt > Use this file to discover all available pages before exploring further. # Deposit sDAI The following method of obtaining sDAI requires users to have DAI first. Head to [https://app.spark.fi/savings](https://app.spark.fi/savings) and connect your wallet. In the **Stablecoins in wallet** section, look for DAI row (you must have DAI in your wallet for this to appear) and click on **Deposit**. Enter DAI amount you want to deposit. Make sure to turn off the **Deposit into Savings USDS** switch. We only want sDAI to interact with Seer. Then in the **Actions** section, click **Approve** to execute the first transaction, and **Convert** to execute the deposit (you must finished approving before the **Convert** button is enabled)**.** Once you have done all the necessary transactions, the specified amount of assets will be deposited and you will receive Savings DAI (sDAI) tokens in return. Make sure to check your wallet for the changes. This documentation is built and hosted on [Mintlify](https://mintlify.com), a developer documentation platform.
