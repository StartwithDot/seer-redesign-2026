The question(s) must be answered on Reality.eth (someone called submitAnswer with sufficient bond). The question(s) must be finalized (e.g. timeout passed, no reopen), so that realitio.resultForOnceSettled(questionId) returns a settled result. If these are not met, the resolution transaction will revert. ​ After resolution: redeeming Once the market is resolved, users can redeem winning position tokens for the underlying collateral via the Router contract (merge and redeem flow). ​ Using @seer-pm/sdk (recommended) The @seer-pm/sdk provides getResolveMarketExecution(marketAddress, chainId) .
