> ## Documentation Index > Fetch the complete documentation index at: https://docs.seer.pm/llms.txt > Use this file to discover all available pages before exploring further. # Applications We expect Seer prediction markets to be initially visible in one general purpose frontend. In order to prevent spam and « tricky » (markets likely to be invalid or markets whose literal interpretation is very different from what most people initially understand) markets, we’ll use Kleros Curate[^kleros-curate] similarly to Omen[^omen]. As the project advances, we could have more specialised frontends, each dealing with a special usecase. Those could even have their own governance. Note that you may not be convinced or support all those applications. But the idea is for Seer to be a neutral protocol (it should still have some limits and abhorrent markets such as assassination markets shouldn’t be listed by frontends nor supported by Kleros) and different contributors would contribute to different usecases. ## References [^kleros-curate]: [Kleros Curate](https://curate.kleros.io/) [^omen]: [Omen](https://aiomen.eth.link) This documentation is built and hosted on [Mintlify](https://mintlify.com), a developer documentation platform.
