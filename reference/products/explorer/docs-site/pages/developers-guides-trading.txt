Quotes go through Lens smart quoter ( lensQuoter ), which picks the best DEX (Uniswap V3/V4 or Swapr) and returns calldata for that DEX’s own router. Swaps execute against the official DEX routers — Lens is not an AMM or a swap router. Use @seer-pm/sdk to get quotes and build swap flows. The SDK handles routing, amounts, and slippage for all supported chains (Gnosis, Ethereum, Base, Optimism). ​ Main collateral by chain Each market’s pool is outcome token / that market’s collateral ( market.collateralToken ).
