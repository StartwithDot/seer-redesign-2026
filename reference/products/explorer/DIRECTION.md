# DIRECTION (binding; written from the user's own words on 2026-10-19; overrides concepts.md / concepts_v1_rejected.md where they conflict)
The user rejected: ledger/field/query-desk concepts, the feed ("Open Floor"), big hero blocks, cards with too little info, and cards that show too much text. The user wants a REAL PREDICTION-MARKET product, minimal, sleek, balanced, easy to navigate, visually appealing, NOT a copy of app.seer.pm (new layout and visuals), every live feature present.

## 1. Home page (markets list)
- Card grid is accepted (EF kit vocabulary; the user chose it), but each card is a trader's card, smaller than the live one so MORE markets fit per screen (target: 5 columns at 1440, 6 at 1920, 2 at 390).
- Hero is slim: ONE trending market rotates one at a time (fade/slide, dots, pause on hover, no marquee), about 72px high. Shows question, big %, Yes/No.
- Left bar: collapsed icon strip by default; opens on hover or click and holds ALL live filters (Market States: All, Reports not open yet, Reports open, Waiting for answer, In Dispute, Pending execution, Closed; Verification Status: All, Verified, Verifying, Challenged, Not Verified; Chain: All, Ethereum, OP Mainnet, Gnosis, Base; Sort By: Default, Liquidity, Volume, Open Interest, Opening Date, Creation Date + Desc/Asc; Conditional Market; Rewards; Minimum Liquidity; Futarchy; Cancel/Apply). Active filters appear as removable tags above the grid. Header keeps Search by market/outcome/collection, Create New Market, My collections, Markets/Leaderboard/Create Market/Policies/App/Connect/help/theme.
- CARD AT REST (what a trader needs, nothing else): avatar, question (2 lines max), the top outcomes with exact % and a BUY control per outcome (Yes/No for binary, Up/Down for scalar, 'Buy' on the top 2 for multi-outcome, '+N more'), volume, a single small TICK for verified (tooltip 'Verified market'; unverified = amber warning mark with tooltip; verifying/challenged have their own marks), a star for collections. No donut, no icon clutter.
- CARD HOVER: a neatly arranged bottom drawer opens (floats over the cards below, grid never jumps; also opens on keyboard focus and click/tap-pin on touch) with the rest, balanced and short: status, liquidity (+ open interest, per-pool on click), type, chain with explorer link, Kleros verification link, Reality.eth link, rewards, conditional parent link, resolution date. Real, clickable links.
- BUY FLOW ON THE CARD: clicking Yes/No/Buy opens a small quick-buy window anchored to the card: shows the chosen outcome + price, a single custom amount input where the user types (no preset chips unless the user asks later), live 'you pay / you get' and 'pays X if it wins', and a Confirm button (wallet-gated: if no wallet, button says Connect; mock wallet rejects signing). Esc/click-away closes.
- The WHOLE CARD is clickable (not just the title) and goes to the market page; the buy buttons, star, tick and drawer links stop propagation.

## 2. Market page (route /markets/<chainId>/<slug>)
Everything else lives here: status strip, question, Answer on Reality.eth (report dialog), meta (type, liquidity, volume, P&L, verified), chart (1D 1W 1M All Custom, honest axis, end labels in a gutter, hover tooltip), outcomes with pool details / Add Liquidity / New conditional market, full trade ticket (Market order, You pay, You will get rounded, avg price, price after, potential return, max slippage 1%, More: Mint/Merge/Redeem, bridge link), Major Events, tabs Comments / Related Conditional Markets / Top Holders / Activity, conditional banner (parent outcome collateral, worthless if parent resolves differently), unverified warning, ids with copy + explorer links. Mobile: ticket is a bottom sheet from a floating button.

## 4. Do not
Equal giant tiles with sparse info, donut charts, tiny unlabeled icon clusters, big hero, marquee, glow/gradients, restyled live layout, dead controls, invented data. Palette: EF neutrals + violet, outcome colors from the approved set, status green/amber/grey. Motion crisp and minimal (hover drawer 180ms, number tick, hero swap 300ms).
