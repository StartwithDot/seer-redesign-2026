## The v2 visual system (use these tokens; define them once in a tokens file / :root block and use var() everywhere)
Dark ("Midnight Violet"): --bg #0A0914, --surface-1 #12101F, --surface-2 #1A1730, --surface-3 #241F40, hairline rgba(185,168,255,.10), text #F2F0FA, muted #A9A3C4, dim #6F688F. Accent family (EF violet): --violet #7B3FF2, --electric #4B3BFF, --lilac #B9A8FF, --mist #E6DEFF; secondary data hue = soft lilac/white tints only; semantic: --up #3DDC97, --down #FF6B81 used sparingly and only for price change; focus ring 2px --lilac.
Light ("Paper Lilac"): --bg #F6F5FB, --surface-1 #FFFFFF, --surface-2 #F0EEFA, --surface-3 #E7E3F7, hairline rgba(40,30,90,.10), text #14122A, muted #55507A, dim #8A85A8; same accents with violet text #5B2FD0 for contrast >= 4.5:1.
Type: Inter Tight (UI, already in the project) + Instrument Serif (display numbers/titles; font files at /fonts/instrument-serif.ttf and -italic.ttf, load with @font-face pointing to ../../fonts or an absolute /fonts path that also works when served from /p/<name>-v2/) + a mono for IDs/addresses only (JetBrains Mono if already bundled). Tabular numerals for every price/percent/amount. Scale: 12/13/14/16/20/28/44/72. Min UI text 12px; body 14-16px. Tracking floor -0.04em.
Depth: layered soft shadows (a tight contact shadow + a wide ambient one), 1px inner top highlight on raised panels, radius 14/20/28, never a hard offset shadow, no glow blobs, no gradient text, no icon-in-coloured-circle template cards, no emoji, no sparkline decoration without data, no numbered section labels.
Icons: redraw ONE consistent icon set as inline SVG (1.6px stroke, round caps, 20px grid) and use it everywhere (replace the old icon sprite/set); icon buttons 40px hit area min.
Buttons: primary = violet fill with a subtle inner highlight and a soft violet shadow, hover = a light sweep + 1px lift, press = scale .98; secondary = surface-2 with hairline; ghost; icon; all with visible focus ring, disabled and loading states. Pills allowed for chips/segmented controls (segmented controls get a sliding thumb animation).
Motion: one authored entrance per view (staggered rise 8-14px + fade, 500-800ms, cubic-bezier(.16,1,.3,1)); numbers count/ease to new values (250-600ms); hover micro-interactions 160-240ms; chart draw-in 900ms; theme change cross-fade 300ms; respect prefers-reduced-motion everywhere (state still readable). 60fps: transform/opacity/clip-path only.
Charts (modern, not default): clean axes with few ticks, direct labels instead of legends where possible, crosshair with a floating tooltip card (glass), smooth monotone curves, gradient area fills under the primary series (opacity <= .22), range brush/segmented range with animated thumb, hover highlighting that dims others, accessible: every chart has an aria-label summary and a keyboard-reachable table fallback or focusable points.
Layout: ≤ 2 viewport-heights of vertical scroll per primary view is NOT required here: these are rich products, but each screen needs ONE clear primary area, consistent 8px grid (4/8/12/16/24/32/48), 1440 main target, true responsive at 1024 and 390 (single column, bottom sheet for trade ticket).
Both themes are first-class: use data-theme on <html> (the shell sets it, key localStorage 'seer.theme', event 'seer:theme'); do not render your own theme toggle or wallet button or global header: the host shell provides them. Keep the product's own second bar (tabs/search) but restyle it.
